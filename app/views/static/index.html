How to Play:

  • Select number of players (2-4) and click "Start Game"
  • Game automatically tracks turns - players continue until they subtract
  • Choose a number between 3 and 15 (numbers can only be used once)
  • Select action: Add (increases score) or Subtract (ends your turn)
  • With 2 players: Ball number 3 gives 6 points!
  • Game ends when all balls (3-15) are used
  • Player with highest score when game ends wins!
